# Medicine Pharmacy Connect

Create a healthcare app web structure. Initialize a Supabase database with tables for: users (with roles: patient, doctor, pharmacist), medicines (including reimbursement status, brand, and generic XPN names), pharmacies (with locations and DTSJ partner badge), and prescriptions (with a 12-digit code, issue date, and 7-day expiration). Setup a clean auth login/signup system based on these roles.
